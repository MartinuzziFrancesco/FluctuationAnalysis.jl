FluctuationAnalysis.jl

FluctuationAnalysis.jl provides fluctuation and scaling analysis of one-dimensional time series. It implements detrended fluctuation analysis and its multifractal, cross-correlation, and moving-average relatives, together with Hurst exponent estimation, on top of a small set of reusable building blocks.

Methods

FunctionMethodPrimary reference
dfaDetrended fluctuation analysis (DFA)Peng et al. (1994)
mfdfaMultifractal DFAKantelhardt et al. (2002)
dccaDetrended cross-correlation analysis (DCCA)Podobnik & Stanley (2008)
dmaDetrending moving average (DMA)Alessio et al. (2002)
mfdmaMultifractal DMAGu & Zhou (2010)
hurstHurst exponent (DFA-based or rescaled range)Hurst (1951); Peng et al. (1994)

Every method shares the same pipeline — integrated_profile, logarithmic_scales, segmentation, detrending through the AbstractDetrender interface, and a loglog_fit — and returns a rich result object whose scaling exponent is read with scaling_exponent.

Installation

using Pkg
Pkg.add(url="https://github.com/MartinuzziFrancesco/FluctuationAnalysis.jl")

Quick start

using FluctuationAnalysis
using Random

series = randn(MersenneTwister(1), 10_000)
result = dfa(series)
scaling_exponent(result)
0.4785760303989923
