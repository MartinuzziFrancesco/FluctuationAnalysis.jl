Getting started

This tutorial walks through a complete detrended fluctuation analysis (DFA) workflow with dfa and introduces the options that every other method in the package shares.

A first analysis

DFA measures how the fluctuations of a signal grow with the size of the window over which they are measured. The slope of that growth in log-log coordinates is the scaling exponent: $0.5$ for uncorrelated noise, larger for positively-correlated signals.

using FluctuationAnalysis
using Random

series = randn(MersenneTwister(1), 10_000)   # uncorrelated white noise
result = dfa(series)
result
DFAResult(exponent=0.4786, scales=20, rsquared=0.9954)

The scaling exponent is read with scaling_exponent:

scaling_exponent(result)
0.4785760303989923

As expected for white noise it is close to $0.5$.

Choosing the scales

By default the scales are generated by logarithmic_scales. You can pass your own range, or tune the generated one:

scales = logarithmic_scales(length(series); minimum_scale=16, maximum_scale=1000)
result = dfa(series; scales=scales)

Restrict the regression to a band of scales without changing which scales are computed using fitrange:

dfa(series; scales=scales, fitrange=(32, 512)) |> scaling_exponent
0.4594082025258834

Choosing the detrender

The local trend removed from each segment is controlled by an AbstractDetrender. The default is a linear PolynomialDetrender; the order keyword is a shortcut for building a higher-order one:

dfa(series; order=2) |> scaling_exponent     # quadratic detrending
0.5073548917078534

Equivalently, pass a detrender explicitly:

dfa(series; detrender=PolynomialDetrender(2)) |> scaling_exponent
0.5073548917078534

Detecting correlations

On a correlated signal the exponent rises above $0.5$. A cumulative sum turns white noise into a Brownian motion, whose DFA exponent is close to $1.5$:

walk = cumsum(randn(MersenneTwister(2), 10_000))
scaling_exponent(dfa(walk))
1.5214369347143557
